# Prism One-Writer Overhaul — end-to-end plan

Date: 2026-06-10 · Status: drafted, pending owner approval
Provenance: 16-agent investigation (7 evidence, 3 skill digests, 3 independent architecture proposals, 3 adversarial judges). Winner: **One-Writer Snapshot-Sync** (2/3 judges), with grafts from *prism-world* (ownership honesty, half-owned file taxonomy) and *Converge* (operator surface, cutover sequencing).

## Canonical sentence

A harness root's Prism-managed footprint is a **pure function** of (plugin corpus, lowerer capability contract, stable MCP runtime identity). The only persistent state is **one snapshot manifest per harness root**, kept solely to answer "may I skip this write?" and "what do I prune?". **One sync engine is the only code that writes harness roots.** Drift is not an error and is never adopted — an externally edited Prism-owned file plans a `repair` (backup + converge to generated bytes), because **source is canonical**. Idempotency is structural, not enforced: the deterministic generator *is* the recovery log.

## Why (root causes, all evidence-verified)

1. **Four writers, three ledger disciplines.** installer (`executeInstallation`), lowering executor (`executeStandardLowering`, shared by 10/11 lowerers), opencode's JSON-patch tail, and the MCP lifecycle (`writeServerBundle` — unledgered, unbacked, non-atomic). The lifecycle writes the *same* `server.mjs` paths the compile ledgers claim → structural drift generator.
2. **Per-plugin claims on whole-world files.** Files like `opencode.json`, codex `config.toml`, and shared union bundles are functions of the full plugin set, but the ledger records per-plugin entries: a shared bundle carries 8 ledger entries (one per co-owning plugin) and only the last writer's hash matches disk. The 49 opencode "drifted" entries are Prism's **own** cross-plugin writes.
3. **Batch-deferred ledger persistence.** `executeStandardLowering` flushes the ledger only after the whole batch; one throw → files written, never recorded → Prism manufactures its own "changed outside Prism" on the next run.
4. **State identity rot.** Ledger IDs bake in `artifact`+`sourcePath`; the artifact value convention flip-flopped (skill → compile → skill) producing **646 zombie duplicate entries** (399 with stale hashes). Test suites wrote the **real** `~/.prism` ledgers: **996 leaked temp-root entries** (612 of opencode's 1600 entries are dead test roots).
5. **Generator nondeterminism at the edges.** Core compile is byte-deterministic, warm-idempotent, and crash-convergent (verified empirically — `fs.ts` temp+rename works). But Bun.build emits cwd-relative module-banner comments that `normalizeBuiltMcpServerBundle` only half-strips; `hook-wrapper-build.ts` strips nothing; ~39% of `~/.claude` churn (6,782 lines) is banner-path rewrites. HTTP bundles bake host/port into bytes.
6. **Secrets and churn pushed to git.** Ephemeral `127.0.0.1` ports are written into `~/.codex/config.toml`, committed, and pushed (skastr0/codex-config). Every daemon restart rotates port → permanent semantic dirt. Whole-document TOML round-trips add ~100 cosmetic line-pairs (indentation, commas, `[projects].last_updated`) per run, burying the 3–4 real hunks. One refresh commit: **426K inserted lines** (1.7 MB bundles in-repo).
7. **Permanent failure states.** No doctor/repair; drift errors have no exit. launchd crash-respawn deadlock: KeepAlive respawns daemon, `runtime.json` pins the dead pid, serve fails "Port in use" forever.
8. **The 2026-06-06 fix series hardened symptoms** (ownership gates, marker write with reader deleted 27 minutes later) — the write/ledger non-transactionality and multi-writer root causes survived every patch.

## End-state architecture

### State model
- `PRISM_HOME/state/roots/<sha256(root)>.json` — **one snapshot manifest per harness root**, replacing all 13 per-harness ledgers. Schema-validated on read (`Schema.parseJson`, tagged-version union). Entries keyed by `(root, targetPath)` **only** — artifact/sourcePath/scope are never identity (zombie class unrepresentable). Fields: `{ targetPath, contentHash, mode: "owned" | "region", regionKey?, plugin }` (plugin = diagnostic attribution).
- Manifest is a **disposable cache**, never the source of truth. Corrupt manifest → quarantine-rename → degrade to converge-with-backup (derive ownership from DesiredState membership), **never** to blocked hard errors. Gate: `rm` the manifest → refresh converges → doctor clean.
- `PrismHome` is an Effect `Context.Tag` service. **No env fallback in library code** — the env read happens only at the CLI edge layer. Tests structurally cannot touch real state. Second fence: snapshot store refuses to persist entries for roots under `os.tmpdir()` outside test layers.
- Advisory lock: `O_EXCL` lockfile under PRISM_HOME, stale-pid takeover, held across plan→apply→commit.

### Write model (the sync engine — the only harness-root writer)
- Lowerers become **pure functions**: `(corpus, capabilities) → { desiredFiles: DesiredTree, regions: Region[] }`. Zero I/O. All validation failures are plan-time typed errors, collected per root (`Effect.partition`, mutation concurrency 1) — one root's failure never aborts another. Collect, don't abort.
- Plan classifies each path: `create / repair / skip / prune / blocked`, each op carrying a **reason** (`new | source-changed | drifted | orphaned`).
- **Invariant (named, tested): skip-before-blocked.** Bytes-equal-desired classifies as `skip` (and is recorded) *before* `blocked` is evaluated. `blocked` fires only for first-time placement over a foreign file whose bytes differ — the *only* guarded case, a typed error with a "delete or move it" hint. No `--overwrite`, no adopt.
- Apply: atomic temp-sibling+rename for every write (already in `fs.ts`; now mandatory for *all* writers including bundles, runtime.json, plists). Orphan `.prism-*.tmp` sweep at run start. Backups: `backups/<runId>/…`, **once per target per run**.
- Commit: snapshot manifest written atomically **last**; the store API enforces commit-last structurally (`apply()` returns entries; `store.commit()` is the only persistence call). kill -9 anywhere → plain re-run converges (renames are atomic; pre-crash writes reclassify as `skip` by byte-equality).
- **One write per shared file per run**: all plugins' regions targeting one shared config merge into a single atomic write (this is also what makes once-per-run backup sound).

### Shared-file regions (config.toml, opencode.json, mcp.json, settings)
- Format-preserving fragment editing only — **never** whole-document round-trips. JSON/JSONC via `jsonc-parser` modify/applyEdits. TOML/YAML: **marker-delimited anchor blocks first** (`# --- prism:<key> begin/end ---` — pattern already exists), table-scoped surgery as a later upgrade only if markers prove ugly. Never touch `[projects].last_updated`.
- Regions are reconstructible by scanning shared files for prism markers/keys → doctor recovery path if a manifest is lost.

### Half-owned file contract (explicit, tested — the prism-world graft)
Whole Prism-generated files living bare-named in shared directories: codex `agents/*.toml`, opencode `agents/*.md`, codex `skills/<orbit>/`, `~/.codex/hooks/*.mjs`. Ownership = **manifest membership** (a prefix predicate provably fails here — verified `builder.toml` sits unprefixed beside user `.bak` files). Per-class tests: prune-on-removal and repair-on-drift.

### MCP model — single writer, single location, stable identity
- All generated servers: `PRISM_HOME/runtime/mcp/<plugin>/server.mjs` — **never inside harness roots**. Harness configs reference Prism-managed Streamable HTTP loopback URLs. Kills: dual mcp-root, N-ledgers-one-path, 1.7 MB bundles in git history, and stdio subprocess storms.
- **One union bundle per plugin** (not per harness); harness-side tool exposure stays deny-by-default through native filters (codex `enabled_tools`, hermes `tools.include`, kimi `enabledTools`) or the HTTP exposure profile header for shared daemon clients.
- Determinism: strip **all** `^// <path>` banner lines (or set `Bun.build` root) in `tool-runtime-bundle.ts` **and** `hook-wrapper-build.ts`; delete `__PRISM_HTTP_PORT__/HOST` compile-time defines — the server reads identity from env + `endpoint.json` at startup. Bundle bytes = f(plugin source, prism version, bun version). CI: build from two cwds × two PRISM_HOMEs → equal sha256; grep-assert no `/Users/`, no port literal.
- Supervisor (`src/mcp/supervisor.ts`, replacing lifecycle write paths): **sole** writer of `runtime.json`/plists, all atomic. Port allocated once and persisted; reallocate only when the recorded daemon is confirmed dead AND the port is foreign-held. Fixes the launchd respawn deadlock (stale-pid check no longer precedes healthy-listener detection; stale-health → auto stop+restart).
- Refresh ordering: build bundles → ensure identity → sync configs → ensure daemons. No `--mcp-lifecycle` modes; no live-daemon compile gate.
- Claude Code escape hatch (if `.mcp.json` resists absolute PRISM_HOME paths): a 2-line owned shim `.mjs` inside the harness-root namespace, an ordinary manifest-owned file, documented as a capability exception. Verify before deleting in-root bundles.

### Error model & CLI surface
- `src/errors.ts`: one `PrismError` Schema.TaggedError union (absorbs CompileError + SnapshotDecodeError, RegionPatchError, BlockedTargetError{targetPath, hint}, BundleBuildError, McpSupervisorError, TokenStoreError…). Rendered **once** at the CLI edge: `Exit.match` → tag→renderer → `process.exitCode`. No stack dumps, ever; every failure line carries a remediation hint. Exit contract: 0 converged/success · 1 domain failure · 2 usage · 3 environment (asserted in CI).
- Verbs: **`prism refresh`** (universal converge: build → sync → ensure daemons) · **`prism plan`** (same pipeline, no apply; diff envelope `codex-cli +3 create ~2 repair(1 drifted) -1 prune =214 skip`) · **`prism doctor [--fix]`** (check families: snapshot-vs-disk, snapshot gc, namespace strays, fragment integrity (present exactly once, parseable), mcp health (pid/port/bundleHash), determinism.selfcheck (rebuild one bundle, compare sha); --fix = regenerate/converge, never adopt) · **`prism mcp status|restart`**.
- `install`, `install-all`, `compile` die. Sandbox debugging = `prism plan --plugin X --root <dir>`. `--dry-run` is sugar for plan. JSON envelope output for agent consumption; human summary derived from it.
- **"Already converged — N verified, 0 written"** is a loud first-class outcome.

## Acceptance gates (the definition of done)

- Fresh clone of stable `~/.codex` / `~/.claude` / `~/.config/opencode` + `prism refresh`: git diff after run 1 contains **only semantic changes** — zero bundles, zero `127.0.0.1:<port>` literals, zero reformat hunks. Run 2: clean tree.
- Two consecutive refreshes: run 2 = `outcome=converged`, zero file writes (`find -newer` empty per root), manifests byte-identical (no updatedAt bump), zero new backups, exit 0.
- kill -9 at 50 random points mid-refresh → plain re-run exits 0, every root byte-identical to clean single-run output, zero manual intervention, no ownership/drift wording anywhere.
- Determinism: same plugin from two cwds × two PRISM_HOMEs → sha256-equal `server.mjs`; bundles grep-clean of `/Users/`, ports.
- Full `bun test` leaves real `~/.prism` hash-identical; zero tmpdir-root entries ever persisted.
- All 72 plugins refresh green on the machine that fails 15/72 today (after cutover); "changed outside Prism"/"not owned by Prism" strings no longer exist in src/.
- Hand-edit an owned file → plan shows exactly one `repair(drifted)`; refresh restores bytes + one backup, exit 0. Foreign file at never-managed path → `blocked` with delete-or-move hint; that plugin fails (exit 1) while all others converge.
- Uninstall cleanliness: remove a plugin from the corpus → refresh → its owned paths, config regions, PRISM_HOME bundle dir, daemon, plist, and runtime state all gone; snapshot has zero references.
- Delete a snapshot manifest → refresh converges → doctor clean (state-is-disposable, executable).
- Daemon killed → launchd respawns → doctor passes and refresh adopts the listener (no "Port in use" loop). Daemon dead + port foreign-held → refresh reallocates and converges end-to-end. 5 restarts → tracked configs byte-identical. Multi-harness refresh of an HTTP plugin restarts its daemon **at most once**.
- Static CI: no `process.exit` outside the edge module; exactly one module (`src/sync/apply.ts`) imports harness-root write primitives; exit-code contract asserted.

## Risks

- WS5 touches 11 lowerers + the installer write path — the big-bang risk. Mitigation: plan-side compile pipeline is already pure and stays intact; only the execute layer is replaced; WS1's acceptance net lands first.
- claude-code `.mcp.json` may resist absolute PRISM_HOME paths — verify early in WS3; shim fallback documented.
- Union bundle exposes all plugin tools to every harness daemon — correctness depends on deny-by-default client-side filters; needs explicit per-harness tests.
- Region editors must survive user-mangled configs — round-trip tests against captured real configs; markers-first keeps the surgery simple.
- Unconditional convergence reverts intentional user edits to owned files (by design — source is canonical); the owned-vs-yours boundary must stay obvious or the owner fights the converge loop.
- Whole-corpus refresh latency: keep the content-addressed compile cache; add a world-level memo keyed on corpus hash so 72-plugin refreshes stay flat.
