# Debug Checklist

## Before Starting
- [ ] Can you reproduce the issue?
- [ ] Do you have the error message/stack trace?
- [ ] What changed recently?

## Investigation
- [ ] Check input values
- [ ] Verify function arguments
- [ ] Review async operations
- [ ] Check external dependencies

## Resolution
- [ ] Root cause identified
- [ ] Fix implemented
- [ ] Tests added/updated
- [ ] Edge cases handled
